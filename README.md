# HelloActions-BraedenBurger

A simple Hello World project for Lab 11 that demonstrates a basic GitHub Actions workflow.

## What it does

The program reads a name from the `WHO_TO_GREET` environment variable (with a default if it isn't set), prints a greeting, and prints a message confirming it ran inside GitHub Actions.

## How it runs

The workflow in `.github/workflows/hello.yml` runs automatically on every push to `main` and can also be started manually from the Actions tab.
